# Calculator

โปรเจกต์เครื่องคิดเลขนี้ใช้ฝึกการจัดการ DOM และการรับเหตุการณ์จากการกดปุ่ม โดยรับค่าจากปุ่มบนหน้าจอมาแสดงผล แล้วส่งไปคำนวณด้วยฟังก์ชัน `eval()` และแสดงผลลัพธ์บนหน้าจอ

🔗 [Live Demo](https://2boycats.github.io/Calculator/)

## ✨ Features
- ปุ่มทุกอันใช้งานได้
- คำนวณผลลัพธ์ได้แม่นยำ
- ลบค่าทีละตัว หรือลบทั้งหมดในครั้งเดียวได้

## 🛠 Tech Stack
- HTML, CSS, JavaScript

## 🚀 วิธีรันโปรเจกต์
1. เปิดโฟลเดอร์โปรเจกต์ด้วย VS Code
2. ใช้ Live Server เปิดไฟล์ `index.html`

## 📝 หมายเหตุ
- โปรเจกต์นี้รองรับเฉพาะการคลิกปุ่ม ยังไม่รองรับแป้นพิมพ์

## 📚 สิ่งที่ได้เรียนรู้
- การจัดการ DOM ควบคู่กับการรับเหตุการณ์ เช่น การคลิก
- การใช้ `eval()` คำนวณนิพจน์ และข้อควรระวังด้านความปลอดภัยของฟังก์ชันนี้

## 🔮 แผนพัฒนาต่อ
- รองรับการกดแป้นพิมพ์
- เปลี่ยนจาก `eval()` เป็นฟังก์ชันคำนวณที่เขียนเอง
